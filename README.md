# Mon Français

日本語UIの個人用フランス語学習アプリ。React / Vite / TypeScript / Dexie (IndexedDB)。外部サーバーやAPIキーは不要です。

## 開発

Node.js 22以上（この環境は24）、npmを使用します。

```sh
cd /workspace/word-repetition-app
npm ci
npm run dev -- --port 5173 --strictPort
```

## 検証

```sh
npm test
npm run build
npm run test:e2e
```

E2EはChromiumを使用します。このクラウドでは `/usr/bin/chromium` が利用できます。別の環境では `CHROMIUM_PATH` を指定するか、`npx playwright install chromium` を実行してください。

本番生成物は `dist/` です。`npm run preview -- --port 4173 --strictPort` で確認できます。Service Workerは本番ビルドでのみ有効です。初回オンライン読み込みとキャッシュ完了後、オフラインで登録・復習・取り込みができます。HTTPSまたはlocalhostが必要です。

## Phase 1

- ホーム：復習待ち・登録数・既知数
- 単語の登録・編集・削除、名詞の性の必須入力、動詞分類・現在活用
- 日→仏、仏→日、聞き取り、文穴埋め。入力・性の選択後に正解表示し、自己採点
- SM-2を基にした復習（初期EF 2.5、1→3→7日、失敗時は翌日にリセット）。期限を迎えた未知カードのみ出題
- 教材・単元・テスト名・タグで絞り込み。期限が近いテストのカードを優先
- CSV / TSV / Google Docs等の表の貼り付け。取り込み前に全行検証・プレビュー
- 既知マーク、CSV書き出し、JSONバックアップ書き出し
- 教材・単元と外部音声リンク

CSV列は `french,japanese,part,gender,example,tags,source,unit,test,deadline`。ヘッダーなしも同じ順で取り込めます。名詞のgenderは `m/f` または `le/la`。品詞は日本語か `noun/verb/adjective/adverb`。期限は `YYYY-MM-DD`。

例文の穴埋めは登録したフランス語の文字列を置換します。活用形の自動解析は行いません。採点は自己採点です。TTSは端末のフランス語音声に依存し、端末に音声がなければ利用できない場合があります。外部音声リンクは通信が必要です。

データはブラウザ・オリジンごとに保存されます。ブラウザデータの削除で消えるため、定期的にエクスポートしてください。CSVで単語を再取り込みできますが、復習履歴・既知状態は引き継ぎません。JSONバックアップは単語帳の復元フォームから追加復元できます。

朝晩クイズ・設定・統計・音声プレイヤー・JSON復元を追加しました。日記・文型チェック・学習時間の記入義務は追加しません。テスト7日前から一律毎日にする案も採用しません。

## GitHub Pages

`npm run build:pages` で `/word-repetition-app/` 向けに生成します。
公開用ファイルは `gh-pages` ブランチ、ソースは `mon-francais-web` ブランチにあります。
GitHubの Settings → Pages → Build and deployment で、Sourceを **Deploy from a branch**、Branchを **gh-pages / (root)** に設定してください。
以後 `mon-francais-web` へのpush時は `.github/workflows/publish-pages.yml` が単体テスト・ビルド後に公開ブランチを更新します（GitHub Actionsが有効である必要があります）。
公開予定URL: https://bohuaxijian94-cyber.github.io/word-repetition-app/
公開サイトの学習データも閲覧者自身のブラウザ内だけに保存します。サイトを削除しても端末内データは自動削除されません。

## 体験デモと使い方

公開サイトの `?demo=1` を開くか、ホームの「デモを試す」を押してください。
サンプル6語が入った専用の単語帳で、4ステップのガイドに沿って操作できます。
通常データは `mon-francais`、デモは `mon-francais-demo` の別々のIndexedDBに保存します。教材のlocalStorageキーも分離しています。
「デモを最初からやり直す」はデモ専用データだけを初期化します。「自分の学習に戻る」で通常データへ戻れます。

1. 「単語帳を開く」で例文・性・教材・タグを見る。
2. 「次の説明へ」→「復習を試す」。「猫」に `chat` と答え、`le` を選択して答え合わせ。「思い出せた」で翌日の復習に送る。
3. 「次の説明へ」→「取り込みを試す」。貼り付け済みサンプルのプレビューを確認して、りんご（pomme）を追加。
4. 「次の説明へ」→「出力ボタンを見に行く」。「CSV出力」で単語リストを保存。

本番では単語帳の「＋ 単語を登録」から授業の単語を追加します。名詞は性を選び、教材・単元・テスト名を付けておくと復習画面で絞り込めます。
「既知にする」はSRSから除外する操作です。「要復習に戻す」で再び出題できます。
復習形式を切り替える場合は、採点前に「出題形式」で選んでください。一度採点するとそのカードは次回期日まで出題されません。

## 今回追加した学習機能

ホームの朝晩クイズは5分間の追加想起練習で、通常のSRS期日は変更しません。設定で新規語数（初期10語/日）、時刻、教材・複数単元によるテスト範囲を変更できます。統計では学習カレンダー・連続日数・習熟度の目安を確認できます。

リスニングには速度調整、リピート、例文・自由入力・リエゾン練習があります。音声は端末依存で、オフラインには端末内のフランス語音声が必要です。通知はアプリを開いている間に動作します。

JSON復元は追加方式で、元のデータを残します。復元前に全内容を検証し、主キーと復習履歴の参照を付け替えます。設定の置き換えは明示チェック時のみ行います。旧JSONバックアップも読み込めます。通常データ・デモは引き続き分離しています。

詳しくは [仕様の見直し](docs/SPEC_REVIEW.md) と [動作確認セルフチェック](docs/SELF_CHECK.md) を参照してください。

## 少ない入力で学ぶ

復習で「声に出して答えた」を選ぶと文字入力を省略できます。対応ブラウザでは「音声で入力」も利用できます（通信やブラウザ提供元への音声送信が必要な場合があります）。音声認識に未対応でも、声に出す自己チェックや端末キーボードの音声入力で続けられます。

統計の「1日以上あけて、思い出せた割合」は既存の通常復習履歴から自動集計する自己採点の参考値です。新たな入力は不要です。根拠と限界は [研究と設計判断](docs/RESEARCH_DECISIONS.md) を参照してください。
