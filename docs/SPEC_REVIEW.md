## 追加した機能

| 項目 | 動作 |
| --- | --- |
| 朝晩クイズ | 5分で終了。夜は今日初めて通常復習したカード。朝は直近の寝る前セット（今日または前日）と期日を迎えたカード。既知は除外 |
| SRSとの関係 | 朝晩クイズは追加想起練習として別記録。通常SRSの期日・EF・成功回数は変更しない |
| 新規単語の上限 | 初期10語/日、設定で1〜100語。登録数ではなく初めて通常復習したカード数で数える。以前に復習したカードは上限外 |
| 設定 | 起床・就寝時刻、新規語数、リマインダー。localStorageに保存、デモとは別領域 |
| 通知 | アプリを開いている間、端末の現地時刻で通知。許可はボタン操作でのみ要求。拒否・非対応時は画面内通知。同じ日の同種通知は1回 |
| 統計 | 通常復習と朝晩クイズの回数、連続日数、91日分ヒートマップ、習熟度の目安 |
| ホーム | 朝・昼・夜のメニューと3つの完了進捗。朝夜は採点で、昼はシャドーイング後の自己申告で完了。15分は目標であり実測値ではない |
| 音声 | 単語例文・自由入力・4種のリエゾン。0.75/1/1.25倍、音声選択、一時停止・再開・停止・リピート。画面移動で停止 |
| テスト範囲 | 教材＋複数単元による範囲を設定画面で登録・編集・削除。復習画面で選択。名前・タグの自由入力絞り込みも継続 |
| 教材 | 教材・単元・外部音声リンクの登録・編集・削除。教材を削除しても単語カードは残す |
| JSON復元 | プレビュー後に既存データへ追加。主キーを再割当てし履歴参照を付け替える。旧バックアップにも対応。時刻・テスト設定・寝る前セットの上書きは明示チェック時のみ |
| バックアップ | 単語・通常履歴・教材・朝晩履歴・設定・シャドーイング完了日。CSVは単語の移行向け、学習状態はJSON向け |

## 実行環境に合わせて明確化した仕様

- ローカル完結・外部サーバーなしを維持する。ブラウザを閉じた状態やスリープ中の正確な定時通知は保証しない。Service Workerだけでは任意時刻の起動を保証できない。
- オフラインでの画面表示・登録・取り込み・復習・統計・復元は、オンライン初回読み込みとService Workerの準備後に利用可能。
- オフライン音声は端末内フランス語音声がある場合に利用できる。ネットワーク音声、出版社・YouTube等の外部リンクは通信が必要。リエゾンの発音は音声エンジンに依存する。
- B1〜B2は学習目標とし、アプリだけでの到達や研究に基づく効果を保証しない。SRSは指定された1→3→7日のSM-2ベースの変種。
- 単語の4出題形式は同じ1枚のSRS状態を共有する。同じ単語を形式ごとに独立して反復したい場合は、別の設計変更として扱う。
- 深夜の寝る前練習にも対応するため、朝は今日・前日に保存された寝る前セットを利用する。前々日以前は繰り越さない。
- 既存データを持つデモ・本番ともにDexie v1を維持。SRSの基本値・アルゴリズムも維持している。

## 承認待ちの変更案（まだ実装しない）

### 日記・文型・学習時間用の保存テーブル

既存 `words` / `reviews` は消さず、Dexie v2で追加する案。

- `diaries`: 日付を主キーに本文、使えた文型ID、更新日時を保存。
- `patterns`: 文型のフランス語、日本語、教材、単元、作成日を保存。日記で使えた文型から通常のWordカードを一度だけ作成。
- `activity`: 日付、学習種類、実際に操作した時間を保存。放置・非表示タブを除外し、15分の実測進捗に使用。
- 本番・デモを同じ移行で別々に更新。旧データ保持・再実行・バックアップ復元・重複カード化防止をテストする。

### 小テスト直前の間隔短縮

- 基本のEF 2.5、1→3→7日、失敗リセットは維持。
- 期限が今日から7日以内の対象カードに限り、次の復習を通常予定と1日後の早い方にする提案。
- 既存期日を自動で書き換えず、次の採点時から適用。期限が過ぎたら通常に戻す。
- 承認前は期日に近いカードの出題順優先のみ。保存したテスト日での間隔短縮は未実装。
