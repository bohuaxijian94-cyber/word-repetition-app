# Phase 2：スマホで使い続けられる設計

## 今回の範囲

既存の朝晩クイズ・設定・通知・統計を、スマホで迷わず操作できる形に統合。機能を増やすことを完了条件にしない。

- 4つの下部タブ：今日／単語帳／記録／その他。常時見せる選択肢を限定する。
- 今日の主操作は復習開始。1日の新規語上限を反映し、上限到達時に開始できない復習を勧めない。
- 起床後・寝る前・音声の追加練習は任意の補助行として表示。
- 復習は声に出して自己チェック→名詞の性→答え合わせ。文字・音声入力、出題形式、テスト範囲は開いた時に表示。
- 単語登録の例文・教材等は任意欄として折りたたむ。バックアップ復元は単語帳の末尾へ移動。
- デモ説明は必要な時に開く。ナビゲーション後は画面先頭へ戻る。
- システムフォント・落ち着いた背景・青い主操作・統一した線画アイコン。AppleのHuman Interface Guidelinesの原則を参考にし、公式アプリを装うことはしない。
- 操作領域44px以上、下部セーフエリア、16px入力、キーボード操作のフォーカス、動きの抑制設定に対応。

## 変えない判断

日記・文型・時間の入力義務を増やさない。保存構造・通常SRSを維持する。通知と音声認識の端末・ネットワーク制約は従来通り。成果の自己評価指標とテストの実成績を混同しない。

## 手動確認

- 390px幅でホームの復習開始が最初の画面内に見える。
- 320px幅でも横にはみ出さず、下部タブ4項目を押せる。
- 声に出す方法なら入力欄を開かずに答え合わせできる。
- 「その他」から設定・リスニング・一括取り込みへ進める。
- 任意欄を開くと例文・教材・テスト情報を入力できる。
- 朝晩クイズ・通知・統計・バックアップ・デモ分離が維持される。

開発時は既存部品・検証を再利用し、対象外の全面再実装や毎回の全文ログ出力を避ける。簡潔な作業案内はルートAGENTS.md。
