# 動作確認セルフチェック

まず体験デモ `?demo=1` で試す。自分の単語帳へ戻るリンクで本番データと分かれていることを確認する。

## 低入力・音声入力

- [ ] 復習で声に出して答え、「声に出して答えた」を選ぶと文字入力なしで答え合わせできる。名詞の性は必須。
- [ ] 次のカードで自己チェックがリセットされ、前のチェックが持ち越されない。
- [ ] 対応ブラウザでフランス語・日本語の音声入力が使える。誤認識は手で直せる。
- [ ] マイク拒否・未対応でも文字入力と自己チェックで続けられる。画面を離れると音声認識が止まる。
- [ ] 音声送信・通信の可能性が操作前に表示される。音声認識を発音の採点に使わない。
- [ ] 履歴がない統計は0%ではなく「まだ記録がありません」。前回から24時間以上あいた通常復習の採点が集計され、件数が表示される。

## 新機能

- [ ] 設定で新規語数を1にして保存。再読み込み後も1になっている。
- [ ] 通常復習で新しいカードを1枚採点。他の未学習カードが今日の通常復習に出ない。
- [ ] ホームの寝る前クイズで今日初めて復習したカードが出る。採点しても単語帳の通常SRS期日が変わらない。
- [ ] 朝ブースターで期日を迎えたカードと直近の寝る前カードが出る。既知カードは出ない。
- [ ] 5分でクイズが終了し、通常復習へ戻れる。
- [ ] 統計で復習回数・連続日数・91日分カレンダーが表示される。
- [ ] 起床時刻を現在時刻の少し後に設定してリマインダーをオン。アプリを開いて待つと通知または画面内メッセージが1回出る。
- [ ] 通知を拒否したブラウザでも画面内メッセージが使える。閉じている間の通知を期待しない。
- [ ] テスト範囲を教材＋複数単元で作り、復習画面でその範囲を選べる。範囲を編集・削除できる。
- [ ] リスニングで例文・リエゾン・自由入力を選び、端末で実際に音が出る。
- [ ] 0.75/1/1.25倍、リピート、一時停止・再開・停止が動く。画面移動で止まる。
- [ ] シャドーイングを完了にするとホームの進捗が増える。再読み込み後も維持される。
- [ ] JSONバックアップを出力し、ファイルを選ぶと復元前プレビューが出る。追加復元後も元のカードが残り、履歴が正しいカードにつながる。
- [ ] 「設定も戻す」のチェックを付けない復元で現在設定が変わらない。不正なJSONは保存前に拒否される。
- [ ] 教材を編集・削除しても、登録済み単語が消えない。

## 既存機能のリグレッション

- [ ] 名詞は性が未選択では登録できない。動詞の分類・活用を保存・編集できる。
- [ ] 日→仏・仏→日・聞き取り・文穴埋めの出題が切り替わる。入力前に答えを表示できない。
- [ ] 通常復習は1→3→7日の間隔、忘れた場合は翌日にリセットされる。
- [ ] CSV・Google Docsのタブ区切り表を取り込める。不正な行があると全体を取り込まない。
- [ ] 既知にすると出題から外れ、要復習に戻すと再び出る。
- [ ] 単語の編集・削除、教材・テスト・タグでの絞り込み、CSV出力が使える。
- [ ] デモをリセットしても通常の単語・教材・設定は残る。
- [ ] 本番ビルドをオンラインで一度開き、準備後オフラインでも再読み込み・登録・復習・統計が使える。
- [ ] スマホ幅で横にはみ出さず、全ナビゲーションを操作できる。

バグ報告：症状／再現手順／期待する動作／ブラウザと端末／表示されたエラーを記録する。
